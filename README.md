# معمل الرسم الفني

تطبيق تعليمي للرسم الفني الصناعي — **مركز تدريب شركة ترسانة الإسكندرية**.

- **لوحة الرسم الخشبية (A3):** مسطرة T، مثلث 45° ومثلث 30/60° (منفردين أو مركّبين)، فرجار، منقلة، أقلام رصاص بدرجات مختلفة، أنواع الخطوط حسب الجدول (2-1)، ألوان للخطوط، أبعاد تلقائية، كتابة باليد، وتقسيم اللوحة.
- **ورقة المربعات (5 مم):** تمارين موجّهة خطوة بخطوة مع تصحيح فوري (سداسي داخل دائرة، تنصيف قطعة مستقيمة).
- **المعمل الافتراضي:** 14 مجسمًا بدرجات صعوبة، تدوير وتفكيك، صندوق الإسقاط وفرده، والمساقط الثلاثة بالزاوية الأولى والثالثة.

## التشغيل على الكمبيوتر (بدون إنترنت)
افتح الملف `Start-Drawing-Lab.bat` — يفتح التطبيق على الشاشة كاملة في متصفح Edge.
أو افتح `index.html` مباشرة بأي متصفح حديث (Edge أو Chrome).

## التشغيل على الموبايل
افتح رابط التطبيق على GitHub Pages من Chrome، ثم من القائمة اختر **«إضافة إلى الشاشة الرئيسية» / «تثبيت التطبيق»**.
يعمل بالوضع الأفقي، وبعد أول فتح يشتغل بدون إنترنت.
